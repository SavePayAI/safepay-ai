# SafePay AI v0.5 — Transaction Guard

## Run
1. Install Node.js 18+.
2. Open Command Prompt in this folder.
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

## What this version does
- Transaction Risk / Pre-Sign Review UI
- Sender, recipient, asset and amount input
- Synthetic demo risk score
- AI-style explanation
- Risk signals
- Transaction summary
- Demo-only "Continue to signing" action

## Important
This is a prototype in DEMO MODE. It does not sign, broadcast, or move funds and it does not claim that synthetic scores are DD/Webacy provider assessments.
